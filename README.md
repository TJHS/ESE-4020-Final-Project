# Virtue of Complexity or Volatility-Timed Momentum?

ESE 4020 final project (Teddy). Tests whether the "virtue of complexity" in market timing (Kelly, Malamud and Zhou, 2024) reflects learning from the predictors or volatility-timed momentum (Nagel, 2025), using a persistence-matched placebo.

## Files
- `ESE_4020_Final_Project_Paper.pdf`: the paper
- `project.ipynb`: reproduces every number and figure in the paper
- `baseline.ipynb`, `baseline.png`: baseline checkpoint
- `PredictorData2025.xlsx`: Goyal-Welch monthly data (sheet "Monthly")

## Data source
Direct link: https://docs.google.com/spreadsheets/d/1qwpl2R_DNujpU5YUkk8lacP1tTeMb9iJ

On Amit Goyal's website (https://sites.google.com/view/agoyal145), it is the "Updated data (up to 2025)" link under Goyal and Welch (2008), "A Comprehensive Look at the Empirical Performance of Equity Premium Prediction".

## How to run
Put `PredictorData2025.xlsx` next to the notebook and run all cells (about 10 minutes, plus about 20 for the neural-network part).
